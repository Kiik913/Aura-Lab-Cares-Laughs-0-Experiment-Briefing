# Aura Lab: Cares & Laughs 0 — Experiment Briefing

Tiny browser lab experiment where your brain farms vibes while the game quietly turns more evil.

## Overview

Aura Lab: Cares & Laughs 0 is a clicker-style web game where you generate **$VG (Vibes Generated)**, level up, and try not to lose all your hearts while the difficulty auto-scales from cozy to cruel.  
The game mixes a simple clicker core, auto-difficulty, upgrades, and a hidden Level 100 "game died" ending.

## Core Gameplay

- Click to generate **vibes** and earn **$VG (Vibes Generated)**.  
- Each good click shows a random line and rewards you with $VG.  
- Levels get harder over time: XP rules get weirder, timers get tighter, and the game feels meaner.  
- Every level has a **countdown timer**. If it hits 0 or you go AFK too long, you lose a **heart**.  
- Lose all hearts and your run ends.

## Systems

- **Vibes & $VG**  
  - Each click gives $VG and may trigger special vibe milestones.  
  - Some milestones drop bonuses or boosts.

- **Levels & XP**  
  - Level up to increase your XP bar and push the game into harsher rules.  
  - Higher levels = stranger XP behavior and tougher progression.

- **Timer & Hearts**  
  - Each level runs on a timer.  
  - Hitting 0 or staying inactive costs a heart.  
  - You start with a limited number of hearts and can increase them via upgrades.

## Upgrades Shop

Spend your $VG to bend the rules instead of just suffering them.

- **Extra Hearts**  
  - Adds an extra life (up to 6 total).  
  - Each purchase increases the price.

- **Time Bender**  
  - Adds extra seconds to the level timer.

- **Brain Overclock**  
  - Increases XP per click.  
  - Stacks up to **+3** levels of power.

- **Background Vibes**  
  - Generates passive $VG per second, even when you are not clicking.

- **Heart Shield**  
  - Blocks the next heart loss.

- **Pro Aura Lab**  
  - Costs **600 $VG**.  
  - Grants a timer buff, XP buff, and a **PRO** title for flex.

## Secrets & Progression

Aura Lab remembers more than you think.

- **Rage Quit**  
  - Unlocks all external rewards once per tab.  
  - After that, it permanently disables itself.

- **Secret Codes**  
  - Certain keyboard sequences (for example, typing `"AURA"`) can instantly unlock everything.

- **Level 100**  
  - Triggers a glitchy "game died" ending and a credits screen.

- **Runs & Persistence**  
  - Reset or Game Over wipes the current run.  
  - Your total $VG in the current browser tab is preserved for future runs.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Kiik913/Aura-Lab-Cares-Laughs-0-Experiment-Briefing.git
   cd Aura-Lab-Cares-Laughs-0-Experiment-Briefing
   ```
2. Open `index.html` in your browser, or use a local server:
   ```bash
   # for example, with Python
   python -m http.server 8000
   # then visit http://localhost:8000
   ```
